# Alloy Helm Chart

Umbrella chart wrapping [Grafana k8s-monitoring](https://github.com/grafana/k8s-monitoring-helm) for comprehensive Kubernetes monitoring with [Grafana Alloy](https://grafana.com/docs/alloy/latest/).

## Features

- Grafana Alloy telemetry collector for metrics, logs, traces, and profiles
- Kubernetes cluster metrics, events, and pod logs collection
- Annotation-based service discovery for application monitoring
- PrometheusOperator object support
- Application observability with OTLP receivers
- Multi-destination support (Grafana Cloud, Prometheus, Loki, Tempo, Pyroscope, etc.)
- Secret management via [idp-app](https://github.com/matuszeman/charts)

## Example: Pod logs to Grafana Cloud

See full example: [`tests/values/examples/pod-logs-grafana-cloud.yaml`](tests/values/examples/pod-logs-grafana-cloud.yaml)

Use `config` (idp-app) to create the credentials Secret, then reference it in the destination:

```yaml
# Create Grafana Cloud credentials Secret via idp-app
config:
  configs:
    grafana-cloud:
      secret: {}
      content:
        loki_username: "123456"
        access_token: "glc_xxxxxxxxxxxxxxxxxxxx"

app:
  cluster:
    name: my-cluster

  destinations:
    grafana-cloud-logs:
      type: loki
      url: https://logs-prod-012.grafana.net/loki/api/v1/push
      secret:
        create: false
        name: <release>-config-grafana-cloud  # generated by idp-app
      auth:
        type: basic
        usernameKey: loki_username
        passwordKey: access_token

  podLogsViaLoki:
    enabled: true

  collectors:
    logs:
      presets:
        - daemonset
        - filesystem-log-reader
```

See [`values.yaml`](values.yaml) for all configuration options and the [k8s-monitoring documentation](https://github.com/grafana/k8s-monitoring-helm) for detailed feature configuration.
